# Wen Rui Sun — Academic Website

A simple, GitHub Pages-ready academic website inspired by the clean, text-focused structure of Liran Rotem's website.

## Files

- `index.html` — site content and navigation
- `style.css` — layout and styling
- `script.js` — functional Home / Research / Personal tabs
- `cv.pdf` — current CV

## Publish with GitHub Pages

1. Create a new GitHub repository, e.g. `wen-rui-sun.github.io`.
2. Upload all four files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save. GitHub will provide your public site URL.

The navigation is intentionally implemented as a single-page site, so all three tabs work without requiring separate folders or pages.

## Easy edits

Open `index.html` to change:
- your biography
- office location
- publications
- talks
- awards
- CV link

The visual design is controlled in `style.css`.
